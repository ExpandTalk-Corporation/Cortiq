# Transfer Impact Assessments (draft) — CortIQ, 2026-10-14

**Status: draft for review by counsel. Not legal advice.** Prepared by Expandtalk Corporation AB (CortIQ) as processor, under Art. 46 GDPR and EDPB Recommendations 01/2020. One assessment per US sub-processor listed in DPA §6.1.

Before relying on these, confirm: (1) CortIQ has accepted each provider's DPA; (2) the provider's DPF status on dataprivacyframework.gov on the date of review.

---

## 1. Supabase, Inc. (database, auth, server functions)

| Item | Assessment |
|---|---|
| Data | All CortIQ processing: page views, sessions, consent records, AI-bot hits, conversion events, hashed emails (SHA-256), account data. IPs truncated before storage; bot IPs nulled after 30 days. |
| Data subjects | Visitors of Customers' websites; Customers' account users. |
| Location | AWS eu-north-1 (Stockholm). Transfer arises only through remote access by Supabase or its sub-processors from outside the EEA (support, operations). |
| Transfer tool | SCCs Module 3 in the Supabase DPA (Decision 2021/914). Supabase's DPA does not rely on the EU-US DPF. |
| Third-country law | US: FISA §702 and EO 12333 can reach electronic communication service providers. EO 14086 and the Data Protection Review Court apply to US intelligence access regardless of DPF certification. |
| Practical likelihood | Low. Data is pseudonymous web analytics with truncated IPs and no direct identifiers; it is of no evident intelligence interest. Supabase publishes no history of government requests for EU customer data (verify its transparency report). |
| Supplementary measures | Storage in the EU; encryption in transit (TLS) and at rest (AWS); IP truncation and short IP retention; hashed emails only; RLS company isolation; least-privilege service-role use in server functions. |
| Conclusion | Transfer may proceed under SCCs with the measures above. Re-assess yearly or if Supabase changes region, DPA or sub-processors. |

## 2. Plus Five Five, Inc. (Resend) — email delivery of exports

| Item | Assessment |
|---|---|
| Data | Report exports emailed on the Customer's request (may contain aggregated or row-level analytics data) and the recipient's email address. |
| Location | USA. |
| Transfer tool | EU-US DPF (adequacy decision 2023/1795, Art. 45) — confirm listing; SCCs Module 3 in the Resend DPA as fallback. |
| Practical likelihood | Low; occasional, Customer-initiated messages. |
| Supplementary measures | Sent only on explicit Customer action; exports above 10k rows are delivered as a time-limited download link from EU storage rather than as an attachment. |
| Conclusion | Transfer may proceed under DPF (primary) and SCCs. |

## 3. Anthropic, PBC — AI insights (CortIQ's own key)

| Item | Assessment |
|---|---|
| Data | Aggregated statistics per site: page paths without query strings, page-view and session counts, device breakdown, form names and conversion rates. No visitor identifiers, IPs or emails. |
| Location | USA. |
| Transfer tool | SCCs Module 3 in Anthropic's Data Processing Addendum (confirm DPF status separately). |
| Residual personal data | Page paths can in rare cases contain personal data (e.g. `/users/jane-doe`). Query strings are already removed. |
| Supplementary measures | Aggregation; path-only URLs; no identifiers; prompts instruct the model to treat data as untrusted. Consider stripping path segments that look like emails or long numeric IDs before sending. |
| Conclusion | Low risk; transfer may proceed under SCCs. |
